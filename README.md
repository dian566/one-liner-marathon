One-liner comedy entry for the [One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2) bounty on make.fun.

## The joke

> My agent promised to fix the bug in five minutes — that was three days ago, and now the bug has its own GitHub repo and two contributors.

## How it works

`main.py` writes the one-liner above, verbatim, to `/output/entry.txt`
(137 characters, no trailing newline). It creates `/output` first if needed.

Run it with:

```sh
python3 main.py
```
